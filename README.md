# D’alma — Pet Sitting em Viseu

Website demonstrativo desenvolvido pela Crisora, com oito páginas, narrativa por scroll, animações GSAP, cena Three.js opcional e formulário que prepara um pedido no WhatsApp.

## Executar

Site estático, sem instalação ou compilação. Sirva esta pasta com um servidor HTTP, por exemplo `python -m http.server 8000`, e abra `http://localhost:8000`.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)`. Os caminhos são relativos e compatíveis com a subpasta `/d-alma/`.

## Conteúdo

Páginas: início, cuidados, passeios, visitas ao domicílio, pet sitting, D’alma, dúvidas e contacto. Fotografias, fontes e bibliotecas estão incluídas localmente.

As fotografias são ilustrativas. A logo utiliza a imagem original com transparência aplicada por SVG; não é uma vetorização. O pedido não confirma uma reserva e só é enviado quando o visitante confirma no WhatsApp. Não há backend, pagamentos, analytics ou armazenamento de contactos.

Protótipo a validar com a D’alma antes do lançamento comercial. O conteúdo mantém `noindex,nofollow`.
